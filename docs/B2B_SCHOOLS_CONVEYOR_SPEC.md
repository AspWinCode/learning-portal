# Конвейер школ: Владелец + Sales-менеджер

## Текущее состояние в коде

- **B2BSchool**: город, pipeline_stage (другие стадии), контакты, события.
- **B2BProject**: main_city, cities — привязка школ к проекту/городу.
- **Owner funnels**: воронки по типам (мероприятия, благодарности, письма поддержки), элементы по школам.
- **Задачи**: TaskTemplate, задачи (нужно увязать с школой и менеджером).

## Целевая модель (из ТЗ)

### Роль 1: Владелец
- Переключатель города: Все / Красноярск / Новосибирск / Иркутск — фильтр школ и задач.
- Экран «План на сегодня»: просроченные шаги, школы без следующего шага, школы в «Найти контакты» > 3 дней, школы на дожим сегодня.
- Импорт школ пачкой (Excel/CSV): город, колонки название, №, адрес/район, сайт; создание со статусом «Новая»/«Найти контакты»; опция «назначить менеджера» и «создать задачи Собрать контакты».
- Канбан по статусам школы (см. ниже).
- Карточка школы: 5 вкладок (Обзор, Контакты, Взаимодействия, Мероприятия и лиды, Документы); быстрые действия: создать задачу, итог звонка, мероприятие, благодарность.
- Постановка задач менеджеру из карточки (шаблоны задач).
- Кампании по городу: цель + список школ + шаблонные шаги; «Сгенерировать задачи менеджеру».
- Аналитика по городу: школы в работе, по стадиям, мероприятия, лиды, топ-школы.

### Роль 2: Sales-менеджер
- Экран «Мои задачи»: сегодня / просрочено / на неделе; школа + город, чек-лист, «Открыть школу», «Отметить шаг», «Итог», «Следующий шаг» (обязательно при закрытии).

### Статусы школ (канбан)

1. Новая  
2. Найти контакты  
3. Первичный контакт  
4. Назначена встреча  
5. Согласование  
6. Запланировано мероприятие  
7. Проведено  
8. Благодарности  
9. Письмо поддержки запрошено  
10. Письмо поддержки получено  
11. Партнеры  
12. Отказ/Заморозка  

### Карточка школы — вкладки

- **Обзор**: город/район, приоритет, теги, статус, следующий шаг (что делать + дата), ответственный, кнопки (задача, итог звонка, мероприятие, благодарность).
- **Контакты**: директор, завуч, учитель информатики, секретарь.
- **Взаимодействия**: лента (звонок/письмо/встреча + итог + следующий шаг).
- **Мероприятия и лиды**: мероприятия, кол-во лидов, конверсия при желании.
- **Документы**: письмо директору, благодарность (PDF), письмо поддержки (статус + файл).

### Задачи (шаблоны для владельца)

- Собрать контакты (дедлайн, куда занести).
- Отправить письмо директору (шаблон, канал, следующий шаг «дожим через 2 дня»).
- Согласовать мероприятие (даты, аудитория, итог во взаимодействия).
- Сделать благодарность (кому, ФИО, PDF, отметить отправку).
- Запросить письмо поддержки (шаблон, напоминание через 5 дней, загрузить файл).

## План реализации (этапы)

### Фаза 1: Основа (данные и фильтр по городу)
- [ ] Расширить `B2BSchoolPipelineStage` (или отдельная таблица статусов) до 12 целевых стадий; миграция.
- [ ] Поле «следующий шаг» (текст) + дата следующего шага у школы; ответственный (manager_id).
- [ ] В кабинете владельца: переключатель города (Все + список городов из школ); все списки/канбан/задачи фильтровать по выбранному городу.
- [ ] API: список городов; школы по городу; обновление следующего шага и даты.

### Фаза 2: План на сегодня
- [ ] API «План на сегодня»: просроченные следующие шаги, без следующего шага, в «Найти контакты» > 3 дней, на сегодня дожим.
- [ ] Страница «Школы → План на сегодня»: таблица/карточки, кнопки: открыть карточку, задача, перенести дату, смена статуса.

### Фаза 3: Канбан и карточка школы
- [ ] Канбан по новым статусам; drag-and-drop; при перемещении — опция «создать типовые задачи».
- [ ] Детальная карточка школы: 5 вкладок (Обзор, Контакты, Взаимодействия, Мероприятия и лиды, Документы); быстрые действия в Обзоре.

### Фаза 4: Задачи, привязанные к школе
- [ ] Модель/связь: задача привязана к школе (school_id), к менеджеру, шаблон; дедлайн, чек-лист (опционально).
- [ ] Владелец: «Создать задачу» из карточки школы — выбор шаблона (Собрать контакты, Письмо, Согласовать мероприятие, Благодарность, Письмо поддержки).
- [ ] Менеджер: экран «Мои задачи» (сегодня/просрочено/неделя); нельзя закрыть без итога и следующего шага по школе.

### Фаза 5: Импорт и кампании
- [ ] Импорт школ из Excel/CSV (город, название, №, адрес, сайт); массовое назначение менеджера и создание задач «Собрать контакты».
- [ ] Кампания: город, цель, список школ, шаблонные шаги; «Сгенерировать задачи менеджеру».

### Фаза 6: Взаимодействия, документы, аналитика
- [ ] Взаимодействия: лента по школе (звонок/письмо/встреча + итог + следующий шаг).
- [ ] Документы: загрузка/хранение файлов (письмо, благодарность, письмо поддержки).
- [ ] Аналитика по городу: школы в работе, по стадиям, мероприятия, лиды, топ-школы.

## Рекомендация по старту

Начать с **Фазы 1**: новые статусы школ, поля «следующий шаг» и дата, ответственный, переключатель города в UI и фильтрация по городу во всех нужных экранах. После этого можно делать «План на сегодня» и канбан.

Если нужно, могу расписать конкретные изменения в моделях, API и фронте по Фазе 1 (миграция, эндпоинты, компонент переключателя города и фильтрация).
