# Runbooks

Операционные и legacy-документы вынесены сюда из корня репозитория, чтобы не засорять верхний уровень проекта.

Основные стартовые точки:
- `QUICK_START.md` — локальный запуск и базовая установка
- `SETUP.md` — общая структура проекта
- `PRODUCTION_SETUP.md` — production setup
- `DEPLOY_CHECKLIST.md` — первый деплой
- `RUNBOOK.md` — operational notes

Отдельные troubleshooting-доки:
- `FIX_*.md`
- `DEPLOY_*.md`
- `LOCAL_*.md`
- `WINDOWS_SETUP.md`, `NODEJS_SETUP.md`, `POWERSHELL_COMMANDS.md`
