# Как увидеть вкладки «Джемы» и «Матрица школ»

На экране кампании должны быть **три вкладки**: «Общая работа» | «Джемы» | «Матрица школ».  
Если их нет — в браузере открыта **старая сборка**. Ниже — как открыть **новую**.

---

## Проверка: какая версия загружена

**Способ 1 — файл версии (без входа в систему)**  
Откройте в браузере: **`https://ВАШ-ДОМЕН/version.txt`** (подставьте свой адрес сайта).
- Видите текст `campaigns-tabs-2025-03` и про вкладки «Джемы» и «Матрица школ» → на сервере отдаётся **новая** сборка. Тогда обновите страницу с очисткой кэша (Ctrl+Shift+R) или откройте сайт в режиме инкогнито и зайдите в «Работа со школами».
- 404 или другой текст → на сервере **старая** сборка; нужен деплой: `git pull`, `docker compose build web --no-cache`, `docker compose up -d`.

**Способ 2 — по интерфейсу**  
1. Зайдите в **Работа со школами** (вкладка «Работа со школами», не «Новая B2B школа»).
2. На экране списка кампаний вверху должен быть **синий баннер**: «Откройте кампанию… — появятся вкладки…».
3. Откройте кампанию — над кнопкой «К списку кампаний» должен быть баннер «Новая версия: ниже три вкладки» и три вкладки: Общая работа | Джемы | Матрица школ.

---

## Вариант 1: запуск с вашего компьютера (актуальный код)

1. **Закройте** все вкладки с этим сайтом.
2. Откройте терминал (PowerShell) и выполните:

```powershell
cd c:\Users\direc\Downloads\learning-portal-main\frontend
npm start
```

3. Дождитесь сообщения вроде «Compiled successfully» (20–40 секунд).
4. В браузере откройте **только** адрес: **http://localhost:3000**
5. Войдите в систему → **Работа со школами** → нажмите **«Открыть»** у кампании.

Должны появиться надпись «Версия: джемы и матрица школ» и три вкладки.

---

## Вариант 2: сайт на сервере (деплой)

На сервере в папке проекта выполните:

```bash
git pull origin main
docker compose build web --no-cache
docker compose up -d
```

На своём компьютере откройте сайт **в режиме инкогнито** (Ctrl+Shift+N) или нажмите **Ctrl+Shift+R** для жёсткого обновления страницы. Снова зайдите в кампанию и проверьте по пункту «Проверка» выше.

## Что может быть не так

| Ситуация | Что сделать |
|----------|-------------|
| Заходите по адресу **сервера** (https://ваш-сайт.ru) | Новая версия там появится только после деплоя: на сервере `git pull origin main`, затем `docker compose build web --no-cache` и `docker compose up -d`. После этого откройте сайт **в режиме инкогнито** или Ctrl+Shift+R. |
| Запускаете `npm start` у себя | Обязательно из папки `frontend`: `cd c:\Users\direc\Downloads\learning-portal-main\frontend`, затем `npm start`. В браузере открывайте **только** http://localhost:3000 (не другой порт и не домен). |
| Уже делали npm start, но баннера нет | Очистите кэш сборки: закройте npm start (Ctrl+C), выполните `rd /s /q node_modules\.cache` в папке `frontend`, снова `npm start`. Откройте localhost:3000 в **режиме инкогнито** (Ctrl+Shift+N). |
| Деплой на сервере уже делали | Убедитесь, что на сервере в папке проекта выполнили `git pull origin main` (чтобы подтянуть последние правки), затем именно `docker compose build web --no-cache` (без кэша), потом `docker compose up -d`. |

## Если всё равно «нет ничего»

- В терминале при `npm start` должен быть путь: `c:\Users\direc\Downloads\learning-portal-main\frontend`.
- В проекте откройте `frontend\src\pages\CampaignsTab.tsx` и найдите текст **«Новая версия: ниже три вкладки»**. Если он есть — код новый; значит, в браузере открыта старая сборка или другой адрес (другой порт/домен).
