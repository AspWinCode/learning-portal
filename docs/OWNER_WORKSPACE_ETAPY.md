# Owner workspace — поэтапная реализация (к ТЗ)

## Сделано в этом проходе (этап «1–3»)

1. **Удаление контакта из проекта** — API уже был; добавлены `removeProjectContact` и UI (список контактов в диалоге проекта + иконка удаления, с подтверждением).
2. **Архив проекта** — в диалоге подтверждения предупреждения: подпроекты, активные задачи, просроченные активные.
3. **Карточка проекта** — редактирование названия, описания, статуса; расширенная статистика задач в API и UI (`total_tasks_count`, `completed_tasks_count`, `overdue_tasks_count`); дата обновления в диалоге; чипы в списке проектов.

## Рекомендуемые следующие этапы

| Этап | Содержание |
|------|------------|
| **4** | Роли и видимость: участник проекта / исполнитель, не только `admin`+`owner` на все эндпоинты |
| **5** | Пагинация/лимит `GET /tasks` (+ UI), уведомления: назначение, комментарий, новое сообщение |
| **6** | Отдельные маршруты или deep-link (`/owner-workspace?tab=…&task=…`) |
| **7** | Карточка контакта: активные/завершённые задачи отдельно, поиск по сообщениям, история по контакту |
| **8** | Раздел настроек задачника (уведомления, MAX, справочники) — по приоритету заказчика |

Файл можно обновлять по мере закрытия пунктов.
