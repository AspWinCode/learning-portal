# 💾 Решение проблемы: "No space left on device"

## Проблема: ENOSPC - недостаточно места на диске

Ошибка `ENOSPC: no space left on device` означает, что на вашем диске недостаточно свободного места для установки npm пакетов.

---

## 🔍 Шаг 1: Проверка свободного места

### Через PowerShell:

```powershell
# Проверка свободного места на всех дисках
Get-PSDrive -PSProvider FileSystem | Select-Object Name, @{Name="Free(GB)";Expression={[math]::Round($_.Free/1GB,2)}}, @{Name="Used(GB)";Expression={[math]::Round(($_.Used/1GB),2)}}

# Или проще:
Get-PSDrive C | Select-Object Used,Free
```

### Через Проводник:

1. Откройте "Этот компьютер"
2. Посмотрите на диск C: (или другой, где установлена система)
3. Проверьте, сколько свободного места осталось

**Для npm install нужно минимум 500 MB свободного места, рекомендуется 2-3 GB.**

---

## 🧹 Шаг 2: Освобождение места на диске

### Способ 1: Очистка диска Windows (Рекомендуется)

1. **Откройте "Очистка диска":**
   - Нажмите `Win + R`
   - Введите: `cleanmgr`
   - Нажмите Enter

2. **Выберите диск C:** (или другой системный диск)

3. **Выберите файлы для удаления:**
   - ✅ Временные файлы
   - ✅ Файлы корзины
   - ✅ Временные файлы интернета
   - ✅ Загруженные файлы программ
   - ✅ Старые файлы Windows
   - ✅ Файлы отчетов об ошибках

4. **Нажмите "Очистить системные файлы"** (если доступно)

5. **Нажмите "ОК"** и дождитесь очистки

### Способ 2: Очистка npm кеша

```powershell
# Очистка кеша npm (может освободить несколько GB)
npm cache clean --force

# Проверка размера кеша
npm cache verify
```

### Способ 3: Удаление ненужных программ

1. Откройте "Параметры" → "Приложения"
2. Найдите неиспользуемые программы
3. Удалите их

### Способ 4: Очистка папки Temp

```powershell
# Очистка временных файлов (будьте осторожны!)
Remove-Item -Path "$env:TEMP\*" -Recurse -Force -ErrorAction SilentlyContinue
Remove-Item -Path "$env:LOCALAPPDATA\Temp\*" -Recurse -Force -ErrorAction SilentlyContinue
```

### Способ 5: Очистка корзины

```powershell
# Очистка корзины
Clear-RecycleBin -Force
```

### Способ 6: Удаление старых файлов Windows

```powershell
# Удаление старых версий Windows (может освободить много места)
# Внимание: это удалит возможность отката к предыдущей версии Windows!
Dism.exe /online /Cleanup-Image /StartComponentCleanup /ResetBase
```

## 📦 Шаг 3: Альтернативные решения для npm install

### Вариант 1: Установка на другой диск

Если у вас есть другой диск с достаточным местом:

```powershell
# Создайте папку node_modules на другом диске
# Например, на диске D:
mkdir D:\node_modules

# Создайте символическую ссылку
New-Item -ItemType SymbolicLink -Path ".\node_modules" -Target "D:\node_modules"

# Теперь попробуйте установку
npm install
```

### Вариант 2: Установка с ограничением места

```powershell
# Установка с минимальными зависимостями
npm install --prefer-offline --no-audit --legacy-peer-deps
```

### Вариант 3: Установка только production зависимостей

```powershell
# Установка без dev зависимостей (меньше места)
npm install --production
```

**⚠️ Внимание:** Это не рекомендуется, так как dev зависимости нужны для разработки.

### Вариант 4: Использование Yarn (может быть эффективнее)

```powershell
# Установка Yarn
npm install -g yarn

# Использование Yarn вместо npm
yarn install
```

## 🎯 Шаг 4: После освобождения места

После того, как освободили место:

1. **Проверьте свободное место:**
   ```powershell
   Get-PSDrive C | Select-Object Free
   ```

2. **Очистите npm кеш:**
   ```powershell
   npm cache clean --force
   ```

3. **Попробуйте установку снова:**
   ```powershell
   cd "C:\Users\direc\Downloads\new project\frontend"
   npm install
   ```

## 🔧 Дополнительные советы

### Проверка размера node_modules (если уже установлен)

```powershell
# Размер папки node_modules
(Get-ChildItem -Path ".\node_modules" -Recurse | Measure-Object -Property Length -Sum).Sum / 1GB
```

### Удаление node_modules и повторная установка

Если установка прервалась:

```powershell
# Удаление node_modules (может освободить место)
Remove-Item -Recurse -Force node_modules -ErrorAction SilentlyContinue

# Удаление package-lock.json
Remove-Item package-lock.json -ErrorAction SilentlyContinue

# Очистка кеша
npm cache clean --force

# Повторная установка
npm install
```

### Использование .npmrc для изменения расположения кеша

Создайте файл `.npmrc` в папке `frontend`:

```ini
cache=D:\npm-cache
```

Или в домашней папке (`C:\Users\direc\.npmrc`):

```ini
cache=D:\npm-cache
```

## 🆘 Если ничего не помогает

1. **Перезагрузите компьютер** - иногда это помогает освободить заблокированные файлы

2. **Проверьте антивирус** - он может блокировать создание файлов

3. **Запустите PowerShell от имени администратора** и попробуйте снова

4. **Используйте другой диск** для установки проекта (если доступен)

5. **Установите только критичные зависимости** вручную:
   ```powershell
   npm install react react-dom --save
   npm install react-scripts --save-dev
   ```

---

## 💡 Профилактика

Чтобы избежать проблем в будущем:

1. **Регулярно очищайте диск:**
   ```powershell
   # Добавьте в планировщик задач
   cleanmgr /d C:
   ```

2. **Настройте автоматическую очистку:**
   - Параметры → Система → Память устройства
   - Включите "Контроль памяти"

3. **Используйте внешний диск** для больших проектов

4. **Регулярно очищайте npm кеш:**
   ```powershell
   npm cache clean --force
   ```
