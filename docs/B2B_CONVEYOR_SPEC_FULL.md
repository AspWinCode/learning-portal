# B2B-школы: полная спецификация конвейера

## 0) Общая логика конвейера (для всех вкладок)

### Основная воронка школы (стратегическая, короткая)

**Стадии:**
1. Новая  
2. Поиск контактов  
3. Контакт установлен  
4. Переговоры  
5. Встреча назначена  
6. Встреча проведена  
7. Разрешение получено  
8. Подготовка  
9. Запланировано  
10. Проведено  
11. Лиды получены  
12. Отказ/Заморозка  

### Ветки (не стадии воронки)

- **Письмо поддержки** — запускается «по кнопке» иногда  
- **Партнёрство** — отдельный процесс со своими шагами  

### Важное правило UX

Школа не должна «висеть» без следующего действия: в карточке школы всегда есть поле **«Следующее действие + дата»**. Если пусто — система подсвечивает и добавляет в «План».

## 1) Вкладка «Новая B2B-школа» (вход и запуск потока)

**Назначение:** быстро создать школу (одну), загрузить пачку (импорт), сразу запустить в работу (задачи + next step), видеть список свежих школ, которые ещё не пошли в конвейер.

### 1.1 Экран: Форма создания

**Поля:** название, город, источник, ответственный, приоритет; (опционально) контакт директора/учителя.

**Кнопки:**
- **Создать**
- **Создать и запустить в работу** (рекомендуемая)
- **Импорт школ из Excel/CSV**

**Сценарий «Создать и запустить»:**
- Пользователь заполняет минимум: название + город + ответственный → «Создать и запустить».
- Система: стадия «Новая»; если контактов нет — следующее действие «Найти контакты» на завтра; создаёт менеджеру задачу «Найти контакты (директор/завуч/информатика)».

### 1.2 Экран: Список «новых» школ

Ниже формы — список школ в стадии «Новая».

**В строке:** школа + город, ответственный, есть ли контакты (0/1/2+), есть ли next step.

**Кнопки быстрых действий:**
- Запустить в работу (→ «Поиск контактов» + next step + задача)
- Назначить ответственного
- Открыть карточку
- Удалить/Архивировать

### 1.3 Сценарий «Импорт пачки»

- Загрузка файла (название/город/адрес/сайт — минимум).
- Система: выбрать город по умолчанию, назначить ответственного (по умолчанию менеджер города), чекбокс «сразу запустить в работу».
- После импорта — список новых школ, «Запустить» для всех или выборочно.

## 2) Вкладка «B2B-школы» (основная работа и контроль)

**Назначение:** рабочая доска — все школы по городам, движение по стадиям, карточка школы, привязка к офлайн/онлайн мероприятию, партнёрство / письмо поддержки «по кнопке».

### 2.1 Верхняя панель

- Поиск школы  
- Фильтр **город**: Все / Иркутск / Красноярск / Новосибирск / Онлайн  
- Фильтр «ответственный»  
- Фильтр «стадия»  
- Фильтр «просрочено»  
- Переключатель вида: **Таблица / Канбан**

### 2.2 Вид «Канбан»

- Колонки = стадии воронки.
- Карточка школы: школа, город; **следующее действие + дата**; кол-во контактов; индикатор «партнёрство»; индикатор «онлайн/офлайн».
- **При перетаскивании** школы на следующую стадию: окно «что сделали» (звонок/письмо/встреча) → заполнить следующее действие + дату → автоматически задача «дожим через 2 дня», если нет.

### 2.3 Вид «Таблица»

Колонки: Школа, Город, Стадия, Ответственный, Следующее действие (и просрочка), Лиды всего, Мероприятий, Партнёрство (статус), Степень дружбы.

### 2.4 Карточка школы (справа, не уводит со страницы)

**A) Шапка:** стадия, ответственный, город, степень дружбы ⭐, следующее действие + дата, кнопки: «+задача», «+взаимодействие», «+мероприятие», «партнёрство», «письмо поддержки».

**B) Контакты:** список; если 0 — кнопка «поставить задачу найти контакты».

**C) Взаимодействия (журнал):** добавить звонок/письмо/встречу с итогом; при добавлении — предложить «следующий шаг».

**D) Мероприятия:** «Добавить мероприятие» → Офлайн (GameJam/обход/встреча) / Онлайн (вебинар, олимпиада, день открытых дверей) / Гибрид. Для онлайн — стандартные задачи: отправить ссылку, рассылка по чатам, напоминания, после проведения — занести лиды.

**E) Лиды:** лиды от школы, источник, «Передать в обработку».

**F) Письмо поддержки:** статус (не требуется / запрошено / получено / архив), «Запросить» → задача + напоминание.

**G) Партнёрство:** чек-лист (пригласили, отправили соглашение, подписано школой, подписано с двух сторон, оригиналы получены, иконка на сайт, активный партнёр); при каждом шаге — следующая задача автоматически.

## 3) Вкладка «План на сегодня» (операционный центр)

**Назначение:** утро — что делать сегодня/завтра/на неделе; риски (конвейер «умирает»); быстро провалиться в школы и исправить.

### 3.1 Верх: фильтр по городу

Все / Иркутск / Красноярск / Новосибирск / Онлайн.

### 3.2 Блок «Сегодня»

Список: задачи менеджера и владельца, next step по школам, просроченные. У пункта: школа/город, что сделать, срок, кнопки «Открыть школу», «Закрыть», «Перенести».

### 3.3 «Завтра» и «Неделя»

Аналогично по срокам.

### 3.4 Блок «Риски процесса»

Кликабельные показатели:
- Школы без следующего действия  
- Школы без контактов  
- Нет касаний 7 дней (в переговорах/подготовке)  
- Мероприятие проведено, лидов нет  
- Переговоры 14+ дней (ревью владельца)  

Клик по числу → список школ → массово назначить действия.

---

## 4) Масштабирование по городам

- Выбор города и работа только по нему.  
- Назначение «ответственного по городу».  
- Сравнение показателей городов.  
- В «Плане» — сводка по городам: школ в работе, просрочек, мероприятий на неделе, лидов за 7 дней, партнёров.

## 5) Автоматизация (триггеры)

| Событие | Действие системы |
|--------|-------------------|
| Создание школы | Если нет контактов → задача «найти контакты» + next step |
| «Контакт установлен» | Задача «первичное касание» + next step «дожим через 2 дня» |
| Отправка письма/сообщения | Задача «дожим через 2 дня», стадия → «Переговоры» (если не там) |
| «Встреча назначена» | «Подтвердить за 1 день», «провести/зафиксировать итог» |
| «Разрешение получено» | Пакет «подготовка мероприятия» (формат/классы/сбор лидов) |
| «Запланировано» | Напоминания за 3 и 1 день + «подготовить материалы» |
| «Проведено» | «Занести лиды» (+ отчёт/благодарности) |
| «Лиды получены» | «Передать лиды в обработку», владельцу — «контроль конверсии через 7 дней» |

**Контрольные проверки (риски в Плане):** нет next step; нет контактов 48ч; нет касаний 7 дней; проведено без лидов 24–48ч; переговоры 14+ дней → ревью владельца.

**Онлайн-мероприятия:** при выборе «Онлайн» — задачи: отправить ссылку, рассылка по чатам, напоминания, после события — занести лиды.

---

## 6) День пользователя (UX)

**Владелец утром:** План на сегодня → город (напр. Красноярск) → Риски → next step/задачи → B2B-школы → канбан → двигает школы.

**Менеджер днём:** План на сегодня → выполняет задачи; в каждой школе фиксирует итог + next step; при «Проведено» → заносит лиды → «Лиды получены».
