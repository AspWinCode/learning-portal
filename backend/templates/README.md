# Шаблон PDF для справки КНД 1151158

Положите сюда файл **`knd_1151158.pdf`** — двухстраничную бланк-форму «Справка об оплате образовательных услуг для представления в налоговый орган» (форма по КНД 1151158).

- Если файл **есть** — при формировании справки данные выводятся **поверх этого шаблона** (подложка = ваша форма, сверху только заполняемые поля). Вид будет как у оригинальной формы.
- Если файла **нет** — справка рисуется с нуля (как раньше).

**Разметка полей** (координаты x_mm, y_mm, ширина ячеек) описана в файле **`KND_1151158_РАЗМЕТКА.md`** в этой же папке. Значения заданы в коде в `backend/app/routers/sales.py` в константах:
- `_KND_OVERLAY_BOXED` — цифровые поля (посимвольно в ячейки),
- `_KND_OVERLAY_TEXT` — текстовые поля (одна строка),
- `_KND_OVERLAY_DATES_PER_CELL` — даты ДД.ММ.ГГГГ по ячейкам,
- `_KND_OVERLAY_CHECKBOXES` — чекбоксы «0 — нет» / «1 — да».

Если ваша форма сдвинута или другого масштаба — подправьте координаты в коде по разметке или по замерам своего бланка.

Файл бланка можно взять с сайта ФНС или отсканировать утверждённый бланк (2 страницы) и сохранить как `knd_1151158.pdf`.
