# 🚀 Установка Node.js - Прямо сейчас!

## ⚡ Быстрая установка (5 минут)

### Шаг 1: Скачайте Node.js

1. **Откройте браузер** и перейдите по ссылке:
   - **Прямая ссылка на LTS версию:** https://nodejs.org/dist/v20.11.0/node-v20.11.0-x64.msi
   - Или откройте: https://nodejs.org/ и скачайте LTS версию

2. **Нажмите на кнопку "LTS"** (Long Term Support) - это стабильная версия

3. **Скачайте установщик** для Windows 64-bit (.msi файл)

### Шаг 2: Установите Node.js

1. **Найдите скачанный файл** (обычно в папке "Загрузки")

2. **Дважды кликните** на файл (например, `node-v20.11.0-x64.msi`)

3. **Следуйте мастеру установки:**
   - Нажмите **"Next"** на первом экране
   - Примите лицензию, нажмите **"Next"**
   - Выберите папку установки (оставьте по умолчанию), нажмите **"Next"**
   - ⚠️ **ВАЖНО:** На экране "Custom Setup" убедитесь, что отмечено:
     - ✅ **npm package manager** (должно быть по умолчанию)
   - Нажмите **"Next"**
   - ⚠️ **ОЧЕНЬ ВАЖНО:** На экране "Tools for Native Modules" отметьте:
     - ✅ **Automatically install the necessary tools** (рекомендуется)
     - Или снимите галочку, если не хотите устанавливать дополнительные инструменты
   - Нажмите **"Install"**
   - Введите пароль администратора, если потребуется
   - Дождитесь окончания установки
   - Нажмите **"Finish"**

### Шаг 3: Проверка установки

1. **ЗАКРОЙТЕ PowerShell полностью** (важно!)

2. **Откройте PowerShell заново**

3. **Проверьте установку:**
   ```powershell
   node --version
   ```
   Должно показать: `v20.11.0` (или другую версию)

4. **Проверьте npm:**
   ```powershell
   npm --version
   ```
   Должно показать: `10.2.4` (или другую версию)

### Шаг 4: Если команды работают - продолжайте!

```powershell
# Переход в frontend
cd "C:\Users\direc\Downloads\new project\frontend"

# Установка зависимостей
npm install

# Запуск проекта
npm start
```

## ❌ Если после установки команды все еще не работают

### Решение 1: Перезапустите PowerShell

1. Закройте все окна PowerShell
2. Откройте новое окно PowerShell
3. Попробуйте снова:
   ```powershell
   node --version
   ```

### Решение 2: Проверьте установку вручную

1. Откройте Проводник
2. Перейдите в: `C:\Program Files\nodejs\`
3. Если папка существует и там есть файлы `node.exe` и `npm.cmd` - Node.js установлен

4. Добавьте в PATH вручную:
   ```powershell
   # В PowerShell (от имени администратора)
   [Environment]::SetEnvironmentVariable("Path", $env:Path + ";C:\Program Files\nodejs", "User")
   ```
   
5. Закройте и откройте PowerShell заново

### Решение 3: Используйте полный путь

Если ничего не помогает, используйте полный путь:

```powershell
# Вместо npm install
& "C:\Program Files\nodejs\npm.cmd" install

# Вместо npm start
& "C:\Program Files\nodejs\npm.cmd" start
```

## 🎯 Альтернатива: Использование Chocolatey

Если у вас установлен Chocolatey (менеджер пакетов для Windows):

```powershell
# Установка Node.js через Chocolatey
choco install nodejs-lts -y
```

3. **Используйте альтернативу:** Yarn или pnpm (но для них тоже нужен Node.js)
