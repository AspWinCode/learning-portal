# Импорт тем в программу обучения из .docx

Страница «Программы обучения» → кнопка **«Импортировать темы (docx)»** на нужной версии
программы позволяет добавить модули и темы из файла Word, не удаляя ничего из уже
существующей структуры.

Backend: `POST /api/v1/programs/{program_id}/import-topics-docx`
(парсер: `backend/app/routers/programs.py`, функция `_parse_topics_docx`).

Файл должен быть в формате `.docx`.

## 1. Структура документа

- **Заголовок 1 (Heading 1)** — название **модуля**.
- **Заголовок 2 (Heading 2)** — название **темы** внутри последнего указанного модуля.
- Обычный текст (стиль «Обычный»/Normal) после Heading 2 — содержимое полей темы.

Пример структуры в Word:

```
[Заголовок 1] Модуль 1: Основы Python
[Заголовок 2] Тема 1: Переменные и типы данных
Описание: разбираем int, str, float, bool
Проект: мини-калькулятор возраста
Результат: ученик создаёт и выводит переменные разных типов

[Заголовок 2] Тема 2: Условия
Описание: if / elif / else
Результат: ученик пишет программу с ветвлением
```

**Важно:** использовать именно стили Word «Заголовок 1» / «Заголовок 2» (Heading 1 / Heading 2),
а не увеличенный жирный шрифт вручную — парсер смотрит на стиль абзаца, а не на визуальное
оформление.

## 2. Подписанные поля темы

Внутри темы (между Heading 2 и следующим заголовком) абзацы должны начинаться с подписи и
двоеточия:

| Подпись | Поле в системе |
|---|---|
| `Описание:` | Описание темы |
| `Проект:` | Проект (необязательное поле) |
| `Результат:` или `Итоговый результат:` | Результат изучения темы |

- Регистр не важен («описание:», «Описание:» — одинаково).
- Если после двоеточия текст переносится на несколько абзацев без новой подписи — они
  присоединяются к последнему указанному полю (через перенос строки), пока не встретится
  новая подпись или новый заголовок.
- Все три поля необязательны — можно указать только «Описание:» или вообще ничего, тогда
  будет создана тема с одним названием.
- Абзацы без узнаваемой подписи, идущие ДО первой подписи внутри темы, игнорируются.

## 3. Что происходит при импорте

- Импорт **добавляется в выбранную программу**, ничего не удаляя.
- **Модуль**: если модуль с таким названием (без учёта регистра) уже есть в программе — темы
  добавятся в него; если нет — модуль будет создан.
- **Тема**: если тема с таким названием уже есть в этом модуле — она **пропускается** (не
  дублируется), поэтому файл можно смело загружать повторно после правок, не боясь задвоения.
- Текст до первого Heading 1 (например, титульная страница/оглавление) игнорируется.
- Если тема (Heading 2) встретилась раньше первого модуля (Heading 1), она попадёт в служебный
  модуль «Без названия» — лучше избегать такой структуры.

## 4. Частые ошибки

- Заголовки сделаны вручную (жирный + крупный шрифт), а не через стиль «Заголовок 1/2» →
  модуль/тема не распознаются.
- Опечатка в подписи поля («Резулььтат:») → строка не привяжется к полю и будет
  проигнорирована (если это первая строка темы) или приклеена к предыдущему полю.
- Файл сохранён не в `.docx`, а в `.doc` или экспортирован из Google Docs без конвертации →
  сервер отклонит с ошибкой формата.
