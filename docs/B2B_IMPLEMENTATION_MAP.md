## Соответствие стадий воронки

**Спека (короткая воронка):**  
Новая → Поиск контактов → Контакт установлен → Переговоры → Встреча назначена → Встреча проведена → Разрешение получено → Подготовка → Запланировано → Проведено → Лиды получены → Отказ/Заморозка.

**Сейчас в коде** (`B2BSchoolPipelineStage`, `PIPELINE_STAGES` во фронте):  
new, find_contacts, first_contact, contact_found, letter_sent, meeting_scheduled, agreement, meeting_held, permission_received, event_scheduled, walkthrough_scheduled, event_done, walkthrough_done, leads_received, thank_you, support_letter_*, partners, rejected.

**Рекомендация:** оставить в БД текущие значения (миграции не обязательны). На фронте ввести **отображаемую** короткую воронку (12 стадий) и маппинг в существующие `pipeline_stage`. Либо добавить новые значения стадий и маппить старые при отображении.

## Рекомендуемый порядок доработок

1. **Воронка и UX:** маппинг 12 стадий спеки ↔ текущие `pipeline_stage`; везде показывать «Следующее действие + дата»; подсветка и добавление в План при пустом next step.  
2. **Новая B2B-школа:** кнопка «Создать и запустить в работу» (стадия, next step, задача); список только «Новая»; быстрые действия в таблице.  
3. **B2B-школы:** переключатель Таблица/Канбан; канбан с drag-and-drop и окном «что сделали» + next step; карточка школы справа с секциями по спеке.  
4. **План на сегодня:** блоки Завтра/Неделя; блок «Риски процесса» с API и кликабельными счётчиками.  
5. **Импорт:** загрузка Excel/CSV, назначение города и ответственного, опция «запустить в работу».  
6. **Автоматизация:** триггеры при создании школы и при смене стадии (задачи + next step).  
7. **Партнёрство и письмо поддержки:** чек-лист партнёрства и статус письма в карточке школы + кнопки и задачи.

Файлы для правок в первую очередь:
