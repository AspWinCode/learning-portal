# Детальное описание страницы «Работа со школами»

Документ описывает страницу `/b2b-schools`: структуру, вкладки, компоненты, поля форм, API и потоки данных.

---

## 1. Общая структура

| Параметр | Значение |
|----------|----------|
| **URL** | `/b2b-schools` |
| **Роли** | Только `owner` |
| **Компонент** | `B2BSchoolsWorkPage` (`frontend/src/pages/B2BSchoolsWorkPage.tsx`) |
| **Редирект** | `/b2b-schools/new` → `/b2b-schools?tab=new` |

Страница состоит из **двух вкладок** (MUI `Tabs`):

1. **«Работа со школами»** (`tab=list`, по умолчанию) — список кампаний и привязка B2B-школ к кампаниям.
2. **«Новая B2B школа»** (`tab=new`) — создание/редактирование B2B-школ, импорт, контакты.

Переключение вкладок через `useSearchParams`: при смене вкладки в URL подставляется `?tab=new` или параметр сбрасывается (для первой вкладки).

## 2. Вкладка «Работа со школами» (CampaignsTab)

Компонент: `frontend/src/pages/CampaignsTab.tsx`.  
Работа идёт с сущностями **Campaign** (кампания) и **SchoolCampaign** (привязка B2B-школы к кампании со стадией участия).

### 2.1. Два режима отображения

- **Режим «Список кампаний»** — когда ни одна кампания не выбрана (`selectedCampaignId === null`).
- **Режим «Детали кампании»** — когда выбрана кампания (клик по строке или кнопка «Открыть»).

### 2.2. Режим «Список кампаний»

**Элементы интерфейса:**

- Заголовок: «Кампании» или «Кампании (архив)».
- Чекбокс **«Показывать архив»** — переключает между активными (draft/active) и архивными (done/canceled) кампаниями.
- Кнопка **«Создать кампанию»** — открывает диалог создания кампании.
- Таблица кампаний:
  - **Название**
  - **Тип** (из `CAMPAIGN_TYPES`: Game Jam, Олимпиада, Лига, Онлайн-ивент)
  - **Формат** (Офлайн / Онлайн)
  - **Город**
  - **Ответственный** (ФИО менеджера)
  - **Статус** (Черновик, В работе, Завершена, Отменена)
  - **Действия**: кнопки «Открыть» и «В архив».

Клик по строке таблицы или «Открыть» задаёт `selectedCampaignId` и переключает в режим деталей кампании.  
«В архив» — вызов `campaignsApi.update(c.id, { status: 'canceled' })`, подтверждение через `window.confirm`.

### 2.3. Диалог «Новая кампания»

Открывается по кнопке «Создать кампанию». Поля:

| Поле | Тип | Обязательное | Описание |
|------|-----|--------------|----------|
| Название | TextField | да | Название кампании |
| Тип | Select | да | game_jam, olympiad, league, online_event |
| Формат | Select | да | offline, online |
| Город | TextField | нет | |
| Регион | TextField | нет | |
| Дата начала | date | нет | |
| Дата окончания | date | нет | |
| Ответственный | Select | нет | Список из `b2bApi.listManagers()` |
| Режим | Select | да | city, region, all_russia |

Кнопки: «Отмена», «Создать». При создании вызывается `campaignsApi.create(...)`, диалог закрывается, список кампаний обновляется.

### 2.4. Режим «Детали кампании»

После выбора кампании отображаются:

- Кнопка **«К списку кампаний»** — сброс `selectedCampaignId`, возврат к таблице.
- Название кампании (заголовок H5).
- Подзаголовок: тип, формат, город, ответственный (из `campaignDetail`).
- Кнопка **«Добавить школы»** — открывает диалог добавления B2B-школ в кампанию.
- **Канбан по стадиям** — горизонтальный скролл колонок (карточки). В каждой колонке:
  - название стадии (из `getStagesForCampaignType(campaignDetail.type)`);
  - количество школ в стадии;
  - список карточек школ: название школы, город, выпадающий список для смены стадии.

**Стадии зависят от типа кампании** (`frontend/src/constants/campaignStages.ts`):

- **Game Jam, Олимпиада, Лига** — `CAMPAIGN_STAGES_GAME_JAM`: не связались → контакт установлен → директор согласен → получен контакт ответственного → согласованы обходы → инфо отправлено родителям → отказ / участвовали / лиды получены.
- **Онлайн-ивент** — `CAMPAIGN_STAGES_ONLINE`: не связались → приглашены → инфо отправлено → подтвердили → отказ / участвовали.

В карточке школы выбор другой стадии в `Select` вызывает `campaignsApi.updateSchoolCampaign(campaignId, sc.id, { stage: newStage })` и обновляет список привязок.

### 2.5. Диалог «Добавить школы в кампанию»

- **Фильтр по городу** — текстовое поле; по потере фокуса или по кнопке «Показать школы» вызывается `campaignsApi.listSchoolsAvailable(campaignId, { city })`.
- Список **доступных школ** (ещё не добавленных в эту кампанию) — мультиселект: id, name, city.
- Чекбокс **«Создать задачу «Связаться со школой» для каждой»** — при добавлении для каждой школы создаётся задача, назначенная ответственному по кампании.
- Кнопки: «Отмена», «Добавить».

При «Добавить» вызывается `campaignsApi.addSchools(campaignId, { school_ids: selectedSchoolIds, create_contact_task: createContactTask })`, затем обновляется список `schoolCampaigns` для текущей кампании.

### 2.6. API вкладки «Работа со школами» (CampaignsTab)

| Действие | Frontend | Backend (роутер `campaigns`) |
|----------|----------|-----------------------------|
| Список кампаний | `campaignsApi.list()` | `GET /api/campaigns` (опционально status, city, type) |
| Создать кампанию | `campaignsApi.create(payload)` | `POST /api/campaigns` |
| Архивация | `campaignsApi.update(id, { status: 'canceled' })` | `PUT /api/campaigns/{id}` |
| Детали кампании | `campaignsApi.get(id)` | `GET /api/campaigns/{id}` |
| Школы в кампании | `campaignsApi.listSchoolCampaigns(campaignId)` | `GET /api/campaigns/{id}/school-campaigns` |
| Доступные для добавления школы | `campaignsApi.listSchoolsAvailable(campaignId, { city })` | `GET /api/campaigns/{id}/schools-available?city=` |
| Добавить школы | `campaignsApi.addSchools(campaignId, { school_ids, create_contact_task })` | `POST /api/campaigns/{id}/school-campaigns/add-schools` |
| Сменить стадию школы в кампании | `campaignsApi.updateSchoolCampaign(campaignId, scId, { stage })` | `PATCH /api/campaigns/{id}/school-campaigns/{scId}` |

При добавлении школ бэкенд создаёт записи `SchoolCampaign` со стадией `not_contacted` и при необходимости задачи «Связаться со школой» (модель `Task`), назначенные ответственному по кампании.

## 3. Вкладка «Новая B2B школа» (B2BSchoolCreateContent)

Компонент: `frontend/src/pages/B2BSchoolCreatePage.tsx` (экспортируется `B2BSchoolCreateContent` без Layout для вставки во вкладку).  
Работа идёт с сущностями **B2BSchool** (школа) и **B2BSchoolContact** (контакт школы).

### 3.1. Блоки интерфейса

1. **Форма создания новой школы** — сверху.
2. **Импорт из файла** — выбор файла, город по умолчанию, опция «Запустить в работу».
3. **Таблица «Созданные школы»** — список B2B-школ с фильтром по городу и действиями (редактирование, контакты, запуск, открыть карточку, удалить).
4. **Диалог «Карточка школы»** — полное редактирование школы + блок контактов.
5. **Диалог «Добавить/редактировать контакт»** — ФИО, должность, телефон, доп. телефон.

### 3.2. Форма создания новой школы

Поля:

| Поле | Тип | Обязательное | Примечание |
|------|-----|--------------|------------|
| Название школы | TextField | да | |
| Директор школы | TextField | нет | |
| Город | TextField | нет | |
| Район | Select | нет | Список из `settingsApi.getB2BDistricts()` |
| Телефон школы (городской) | TextField | нет | Минимум 5 цифр при заполнении |
| Приоритет | Select | нет | high, medium, low, пусто |
| Адрес | TextField | нет | |
| Количество детей в школе | number | нет | |
| Степень дружбы | Select | нет | unknown, indirect, friends, enemies |
| Стадия воронки | Select | да | Список из `ALL_FUNNEL_STAGES` (b2bFunnel.ts) |

Кнопки:

- **«Создать школу»** — сохранение с текущими полями (в т.ч. `pipeline_stage` из формы).
- **«Создать и запустить в работу»** — создание с `pipeline_stage: 'find_contacts'`, `next_step: 'Найти контакты (директор/завуч/информатика)'`, `next_step_date`: завтра.

После успешного создания — сообщение об успехе, сброс формы, обновление списка школ.

### 3.3. Импорт из файла

- Кнопка «Выбрать Excel/CSV» — выбор файла (`.xlsx`, `.csv`).
- Поле **«Город (по умолчанию)»** — подставляется всем строкам, у которых в файле нет города.
- Чекбокс **«Запустить в работу»** — для каждой созданной школы выставляются стадия `find_contacts`, следующий шаг и дата (завтра); на бэкенде при опции может требоваться указание менеджера (в текущем фронте передаётся только `launch_in_work`).
- Кнопка **«Загрузить»** — отправка `b2bApi.importSchools({ file, city, launch_in_work })`.

Формат файла: первая строка — заголовки. Ожидаемые колонки (по названию): название (обязательно), директор, город, адрес, учеников (количество). Бэкенд поддерживает варианты имений (название/name/школа/school и т.д.).

После импорта показывается результат: создано, пропущено, список ошибок (если есть).

### 3.4. Таблица «Созданные школы»

Колонки: Название, Директор, Город, Адрес, Учеников, Контакты (количество), Ответственный, След. действие (текст + дата), Стадия, Действия.

- **Фильтр по городу** — выпадающий список городов из уже загруженных школ.
- Строки без следующего действия (`hasNoNextAction(school)`) подсвечиваются (серый фон).
- Клик по строке — открытие диалога «Карточка школы» (редактирование).

В колонке «Действия»:

- **Запустить в работу** (иконка Play) — `pipeline_stage: 'find_contacts'`, следующий шаг и дата завтра.
- **Назначить ответственного** (иконка Person) — открывает ту же карточку школы (редактирование менеджера и остального).
- **Открыть карточку** (иконка OpenInNew) — `navigate('/b2b-schools?open=' + school.id)`. Примечание: параметр `open` на странице в текущей реализации не обрабатывается (остаётся для перехода из «Плана на сегодня» или будущего функционала).
- **Удалить** (иконка Delete) — подтверждение и `b2bApi.deleteSchool(school.id)`.

### 3.5. Диалог «Карточка школы»

Открывается при клике по строке в таблице или по кнопке «Назначить ответственного». Данные подгружаются через `b2bApi.getSchool(school.id)`.

Поля редактирования (совпадают с полной моделью B2B-школы):

- Название школы, Директор, Город, Адрес.
- Количество детей в школе.
- Степень дружбы.
- Стадия воронки (все стадии из `ALL_FUNNEL_STAGES`).
- Следующий шаг, Дата следующего шага.
- Ответственный (менеджер) — выбор из `b2bApi.listManagers()`.

Условные поля по стадии:

- При стадии **«Встреча назначена»** (`meeting_scheduled`) — поле «Когда назначена встреча» (datetime-local).
- При стадии **«Встреча проведена»** (`meeting_held`) — поле «Основные итоги встречи» (многострочное).
- При стадии **«Назначена дата обхода»** (`walkthrough_scheduled`) — поле «Дата обхода» (date).

Блок **«Контакты»**: список контактов школы, кнопка «Добавить контакт», для каждого контакта — редактирование и удаление. Сохранение контакта — валидация телефона (маска +7, 10 цифр), вызов `b2bApi.createContact` или `b2bApi.updateContact`.

Кнопки диалога: «Закрыть», «Сохранить». Сохранение — `b2bApi.updateSchool(editingSchool.id, payload)` с приведением дат (meeting_scheduled_at, walkthrough_scheduled_at, next_step_date) в зависимости от стадии.

### 3.6. Диалог контакта (добавить/редактировать)

Поля: ФИО (обязательно), Должность, Контакт (телефон, обязательный, маска и валидация), Дополнительный контакт (телефон). Кнопки: «Отмена», «Сохранить».

### 3.7. Стадии воронки B2B-школы (pipeline_stage)

Используется константа `ALL_FUNNEL_STAGES` из `frontend/src/constants/b2bFunnel.ts`. Примеры стадий: Новая, Поиск контактов, Первичный контакт, Контакт установлен, Письмо отправлено, Переговоры, Встреча назначена, Встреча проведена, Разрешение получено, Запланировано мероприятие, Назначена дата обхода, Проведено, Обход проведён, Лиды получены, Благодарности, Письмо поддержки запрошено/получено, Партнёры, Отказ/Заморозка.

### 3.8. API вкладки «Новая B2B школа»

| Действие | Frontend | Backend (роутер `b2b`) |
|----------|----------|------------------------|
| Список школ | `b2bApi.listSchools()` | `GET /api/b2b-schools` (опционально city, pipeline_stage, manager_id, overdue, search) |
| Одна школа | `b2bApi.getSchool(id)` | `GET /api/b2b-schools/{id}` |
| Создать школу | `b2bApi.createSchool(payload)` | `POST /api/b2b-schools` |
| Обновить школу | `b2bApi.updateSchool(id, payload)` | `PUT /api/b2b-schools/{id}` |
| Удалить школу | `b2bApi.deleteSchool(id)` | `DELETE /api/b2b-schools/{id}` |
| Импорт | `b2bApi.importSchools({ file, city, launch_in_work })` | `POST /api/b2b-schools/import` |
| Контакты: список | в составе `getSchool` | `GET /api/b2b-schools/{id}/contacts` |
| Контакты: создать | `b2bApi.createContact(schoolId, payload)` | `POST /api/b2b-schools/{id}/contacts` |
| Контакты: обновить | `b2bApi.updateContact(schoolId, contactId, payload)` | `PUT /api/b2b-schools/{id}/contacts/{contactId}` |
| Контакты: удалить | `b2bApi.deleteContact(schoolId, contactId)` | `DELETE /api/b2b-schools/{id}/contacts/{contactId}` |
| Менеджеры | `b2bApi.listManagers()` | `GET /api/b2b-schools/managers` |
| Районы | `settingsApi.getB2BDistricts()` | Настройки (отдельный API) |

После создания школы бэкенд может создавать задачи (например, при «запуске в работу») через `_on_b2b_school_created`. При смене стадии вызывается `_on_b2b_school_stage_changed` и т.п.

## 4. Связь с другими страницами

- **План на сегодня** (`/b2b-schools/plan`): ссылка на школу открывает `/b2b-schools?open={id}` в новой вкладке.
- **Воронки владельца** (`/owner-funnels`): есть переход на `/b2b-schools`.
- После создания школы в форме «Новая B2B школа» (отдельная страница `B2BSchoolCreatePage`) выполняется `navigate('/b2b-schools?open=' + school.id)`. На объединённой странице с вкладками параметр `open` сейчас не обрабатывается — при необходимости можно в `B2BSchoolCreateContent` при монтировании читать `searchParams.get('open')` и открывать карточку школы с этим id.

## 5. Резюме по данным

| Вкладка | Основные сущности | Назначение |
|---------|-------------------|------------|
| Работа со школами | Campaign, SchoolCampaign | Кампании (Game Jam, олимпиады и т.д.) и привязка к ним B2B-школ со стадиями участия; добавление школ в кампанию, смена стадии. |
| Новая B2B школа | B2BSchool, B2BSchoolContact | Справочник B2B-школ: создание, редактирование, контакты, импорт из Excel/CSV, «запуск в работу», удаление. |

Оба раздела используют общий справочник **B2BSchool**: школы, добавленные во вкладке «Новая B2B школа» (или через импорт), затем могут быть добавлены в кампании на вкладке «Работа со школами» через «Добавить школы».
