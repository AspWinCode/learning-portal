# Импорт программы обучения курса из .docx (Студия методиста)

Страница «Студия методиста» → карточка курса → кнопка **«Импортировать программу»**
позволяет загрузить программу обучения (модули → подмодули → темы → занятия) из файла
Word вместо создания уроков вручную по одному.

Backend: `POST /api/v1/course-studio/courses/{course_id}/import/preview` (предпросмотр,
ничего не сохраняет) и `POST /api/v1/course-studio/courses/{course_id}/import/commit`
(сохранение). Парсер: `backend/app/services/course_program_docx.py`.

Файл должен быть в формате `.docx`, размер — не более 10 МБ.

## 1. Структура документа

Уровни вложенности задаются стилями заголовков Word:

| Стиль Word | Уровень |
|---|---|
| **Заголовок 1** (Heading 1) | Модуль |
| **Заголовок 2** (Heading 2) | Подмодуль — **необязателен** |
| **Заголовок 3** (Heading 3) | Тема |
| **Заголовок 4** (Heading 4) | Занятие |

**Важно:** нужны именно стили Word «Заголовок 1/2/3/4», а не увеличенный/жирный шрифт
вручную — парсер смотрит на стиль абзаца, а не на визуальное оформление.

Если в модуле нет ни одного Heading 2, темы (Heading 3) крепятся напрямую к модулю —
подмодуль использовать не обязательно.

Пример структуры в Word:

```
[Заголовок 1] Модуль 1: Основы
[Заголовок 2] Подмодуль А: Переменные          ← можно пропустить, если подмодули не нужны
[Заголовок 3] Тема 1: Числа и строки
[Заголовок 4] Занятие 1: Знакомство с типами
Обычный текст теории занятия.
Ещё абзац теории, можно с **жирным** и *курсивом* текстом.
Домашнее задание: решить 5 задач на типы данных

[Заголовок 4] Занятие 2: Ввод и вывод
Текст занятия 2…

[Заголовок 3] Тема 2: Условия
[Заголовок 4] Занятие 3: if / elif / else
...

[Заголовок 1] Модуль 2: ООП
[Заголовок 3] Тема 1: Классы             ← без подмодуля, тема сразу под модулем
[Заголовок 4] Занятие 1: Первый класс
...
```

## 2. Текст занятия и домашнее задание

Все обычные абзацы между заголовком занятия (Heading 4) и следующим заголовком любого
уровня становятся содержимым занятия:

- Абзац, начинающийся со слов **«Домашнее задание»** (регистр не важен, с двоеточием или
  без), делит текст занятия на две части: всё **до** него уходит в поле «Теория», всё
  **после** — в поле «Домашнее задание».
- Если такого абзаца нет — весь текст попадает в «Теорию», поле «Домашнее задание»
  остаётся пустым (его можно заполнить вручную после импорта).
- Жирный и курсивный текст (Bold/Italic в Word) конвертируется в markdown (`**жирный**`,
  `*курсив*`).
- Абзацы со стилем списка («Маркированный список» / «Нумерованный список») превращаются
  в markdown-список (`- пункт` / `1. пункт`).

## 3. Что происходит при импорте

- Перед сохранением всегда показывается **предпросмотр**: дерево модулей/подмодулей/тем/
  занятий и список предупреждений — можно проверить структуру до подтверждения.
- Импорт **добавляет новое дерево модулей к уже существующим** в курсе — ничего не
  удаляется и не объединяется с прежними модулями. Если нужно заменить программу целиком,
  сначала вручную удалите старые модули (кнопка удаления модуля), затем импортируйте файл
  заново.
- Повторная загрузка того же файла создаст **дубликат** дерева модулей — в отличие от
  импорта тем в Program/Module/Topic, здесь нет сопоставления по названию.
- Каждое занятие становится обычным уроком (`CourseLesson`) — его можно после импорта
  редактировать как любой другой урок курса.

## 4. Предупреждения и ошибки

Импорт остановится с ошибкой, если:

- в документе нет ни одного Heading 1 (ни одного модуля);
- подмодуль (Heading 2), тема (Heading 3) или занятие (Heading 4) встретились раньше
  своего обязательного родителя (например, тема до первого модуля).

Импорт пройдёт, но покажет предупреждение в предпросмотре, если:

- модуль не содержит ни одной темы;
- тема не содержит ни одного занятия;
- занятие идёт без единого абзаца текста (пустое).

## 5. Частые ошибки при подготовке файла

- Заголовки сделаны вручную (крупный жирный шрифт), а не через стили «Заголовок 1–4» →
  уровень не распознаётся, всё попадает как обычный текст.
- Перепутаны уровни заголовков — например, занятие оформлено как Heading 3 вместо
  Heading 4 → парсер примет его за тему без занятий.
- Файл сохранён не в `.docx` (например, `.doc` или экспорт из Google Docs без
  конвертации) → сервер отклонит с ошибкой формата.
- Слово «Домашнее задание» написано с ошибкой или является частью обычного предложения
  (не отдельным абзацем) → текст не разделится, всё уйдёт в «Теорию».
